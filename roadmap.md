# Product Roadmap

Roadmap sequencing is provisional and should change based on user research, technical feasibility, and safety review.

## Stage 0 — Validate the problem
- Interview older adults, remote family supporters, and caregivers.
- Map current medication and emergency communication workflows.
- Test willingness to share routine-care information.
- Identify language, accessibility, connectivity, and device constraints.

**Exit criteria:** evidence of a repeated problem, clear user segments, and validated priority workflows.

## Stage 1 — MVP: dependable routine coordination
- Account setup and consent-based family invitations.
- Medication schedule and reminders.
- Taken / skipped / unconfirmed event logging.
- Basic family dashboard with data freshness.
- Emergency profile and user-triggered contact alert.

**Why this first:** these capabilities test the core value proposition without depending on predictive AI or complex clinical interpretation.

## Stage 1.5 — Reduce input friction
- Prescription image capture and OCR draft.
- Mandatory human review and confirmation.
- Family text / voice notes.
- Additional language support based on pilot demand.

## Stage 2 — Connected care
- Optional wearable integrations.
- Caregiver workflows.
- Teleconsultation or service integrations after partner and compliance review.
- Fall detection only after feasibility, false-positive, and response-process validation.

## Stage 3 — Ecosystem
- Healthcare provider, insurer, and home-care partnerships.
- Feature-phone / IVR access where user research supports it.
- Expansion to families supporting older adults across borders.

## Prioritisation rule
Prioritise features by user value, frequency of need, implementation effort, safety risk, and dependency. Do not advance a feature merely because it uses AI.
